# SubhAadar 🌟

A magical, interactive fun app for kids! Type on the keyboard or touch the screen to see colorful animations, alphabet popups, emoji bursts, fireworks, and more!

## Features
- 🌈 Rainbow animated letter popups on every keypress
- 🎉 Emoji bursts (50+ fun emojis)
- 📸 Photo popups (add your child's photos!)
- ✨ Star burst and fireworks effects
- 🎯 Glowing cursor trail
- 🎆 Milestone celebrations (10, 25, 50, 100... keys!)
- 📱 Mobile on-screen keyboard for touch devices
- 🔄 Auto idle demo mode
- 🌙 Animated floating background shapes
- Score counter

## How to Add Photos
Place your child's photos in the `photos/` folder:
- `photos/photo1.jpg`
- `photos/photo2.jpg`
- `photos/photo3.jpg`

Then update the `PHOTOS` array in `index.html` if you add more.

## Play Online
Open `index.html` in any modern browser or visit the GitHub Pages URL.
